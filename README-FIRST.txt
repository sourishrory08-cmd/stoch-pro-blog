STOCH PRO — MINIMAL VERSION
===========================

1. Open this folder in VS Code.
2. Open Terminal -> New Terminal.
3. Run:

   quarto preview

The terminal must be inside the folder that directly contains _quarto.yml.

MAIN FILES
----------
index.qmd       Home page
lectures.qmd    Lecture index
styles.scss     Site design
_quarto.yml     Quarto configuration
posts/          Future lecture files

LECTURE 1
---------
The first lecture should be saved as, for example:

posts/01-markov-chains.qmd

Do not replace index.qmd. It is the permanent home page.
